# Hawaii Thrive Detail Page Layout Reference

## Layout Structure
- Full-width cover image (hero) with FEATURED + CLAIMED badges overlaid on top-left and top-right corners
- Back button top-left, "Login to Follow" top-right
- Business name as H1 below the cover image
- Two-column layout below: main content (left, ~65%) + sidebar (right, ~35%)

## Main Content (left column)
- Business name + category breadcrumbs
- Cover image with badge overlays (FEATURED badge red/left, CLAIMED badge blue/right)
- About / Description section
- Hours of operation (table format)
- Photo gallery (grid)
- Map embed
- Reviews / Google Reviews widget

## Sidebar (right column)
- "Get More Information" card
  - Plan type badge
  - Claim this business button (if unclaimed)
  - Phone number (clickable tel: link)
  - Address
  - Email
  - Website link
  - Social media icons (Facebook, Instagram, etc.)

## Key Visual Elements
- FEATURED badge: red pill, lightning bolt icon, top-left of image
- CLAIMED badge: blue pill, checkmark/shield icon, top-right of image
- Clean white background, minimal design
- Category shown as breadcrumb tags below business name

## Plan Features to Show by Tier
- Free: name, category, address, phone
- Gulf Breeze (Featured): + description, hours, website, email, social links, map
- Island Premier (Sponsored): + photo gallery, Google Reviews widget, priority placement
